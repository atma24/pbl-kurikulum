# Panduan Registrasi Akun Dosen (Hak Akses: KPS/Kaprodi)

Dokumen ini menjelaskan alur operasional bagi Ketua Program Studi (KPS) untuk mendaftarkan akun Dosen baru ke dalam Sistem Informasi Pengelolaan Kurikulum dan KKN.

## 1. Persiapan Data
Pastikan KPS telah memiliki data valid Dosen yang bersangkutan:
* Nama Lengkap beserta Gelar
* NIP (Nomor Induk Pegawai)
* Email Resmi Institusi (contoh: dosen@polman-bandung.ac.id)

## 2. Alur Registrasi via Antarmuka Web
1. Buka tautan sistem yang telah diberikan oleh Administrator.
2. Login menggunakan akun **Kaprodi** Anda.
3. Pada halaman *Dashboard*, navigasikan menu ke **Manajemen Dosen**.
4. Klik tombol **+ Register Dosen Baru**.
5. Isi formulir pendaftaran dengan data Dosen yang valid.
6. Masukkan **Password Awal** (contoh standar: `Polman2026!`). Dosen diwajibkan untuk mengubah kata sandi ini setelah login pertama kali.
7. Klik **Simpan & Daftarkan Dosen**.

## 3. Validasi
Setelah disimpan, data Dosen akan langsung muncul pada tabel Daftar Dosen Terdaftar. Dosen yang bersangkutan kini dapat login menggunakan NIP/Email dan kata sandi awal yang telah Anda buatkan.
